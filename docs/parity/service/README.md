# Сервис: библиотека, бумаги, религия, досуг, уборка
Механики сервисных профессий и досуга из оригинала: библиотека и книги (`code/modules/library`), канцелярия и офисные машины (`code/modules/paperwork`, модпак `paperwork`), фотография, религия и капеллан, музыкальные инструменты и музыкальный автомат (модпаки `music`, `jukebox`), живопись и скульптура, карты/кости/игровой автомат, голодек, рыбалка и аквариумы, уборка и стирка, косметика и зеркала, клоун и мим, наклейки на ID (модпак `id_stickers`). В ss13-rs почти ничего из этого нет: предметы с карты существуют как обычные вещи (некоторые хранилища работают через общий `storage.rs`), но собственных механик нет.
