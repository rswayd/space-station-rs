# Турели, сканер-ворота и баррикады
Автоматическая защита (турели и их пульты), досмотровые ворота и переносные заграждения.

### Портативная турель
Скрывается под крышкой и выдвигается при цели в радиусе 7; стреляет оглушающими или летальными снарядами (`stun_projectile`/`lethal_projectile`, задержка 1.5 с). Оценка угрозы (`assess_perp`): статус розыска в записях, неавторизованное оружие без доступа, отсутствие ID, отсутствие майндщита, киборги, главы — по флагам; ЭМИ/емаг сбивают настройки. Настраивается ID с доступом через окно tgui.

- **Код:** [`/obj/machinery/porta_turret`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/porta_turret/portable_turret.dm#L27), [`proc/assess_perp()`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/porta_turret/portable_turret.dm#L587), [`proc/shootAt()`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/porta_turret/portable_turret.dm#L637), [`proc/popUp()`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/porta_turret/portable_turret.dm#L548); tgui: [`PortableTurret.jsx`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/tgui/packages/tgui/interfaces/PortableTurret.jsx)
- **Статус в ss13-rs:** ✅ реализовано — `crates/ss13_game/src/defenses/server.rs` (`Turret`), данные `DmTurret` (`crates/ss13_mapload/src/guns.rs`: снаряды и звуки из установленного оружия, `get_turret_properties`): раз в 2 с (`SSturrets`) включённая запитанная турель смотрит мобов в `scan_range` с линией видимости, выбирает случайную цель, выдвигается (0.5 с), поворачивается и стреляет оглушающим/летальным снарядом после `shot_delay`; без целей задвигается. `assess_perp`: емаг/ярость — 10, главы — 0 без флага, оружие без доступа 4/2 (кроме хамелеон-ID), розыск или нет записи — 4, без майндщита — 4; базовые мобы по фракции, киборги по флагу. Окно `PortableTurret` (питание, флаги целей; заперто — только силиконы, проверка на сервере), ID с доступом запирает; емаг (всё цель, пульты не управляют, выкл. 6 с), ЭМИ (флаги, выкл. 6–20 с). Урон через `crate::obj_damage` (160, броня ближнего боя): 30 % искр, включённая турель 6 с стреляет во всех без её доступа (`TURRET_FLAG_SHOOT_ALL_REACT`), на половине ломается (`_broken`, выключена навсегда, искры), ноль — уничтожена; лом по сломанной (2 с) — 70 % вернуть оружие и по 50 % 1–4 листа железа и датчик движения; гаечный ключ откручивает/прикручивает выключенную опущенную турель (откручённая — закрытая крышка, не работает); мультитул запоминает незапертую турель; выстрел тратит `reqpower` (летальный ×2); турель в стене стреляет с первой свободной соседней клетки к цели (прямо или ±45°). Чужое: анимация крышки (отдельный объект крышки и `flick` — эффекты/рендер; крышка — спрайт самой турели), броня объектов по типу снаряда (снаряды бьют через броню ближнего боя — общий механизм `crates/ss13_game/src/projectile.rs`, ../combat/). Не нужен `wall_turret_direction` (на картах не задаётся)

- **Статус в ss13-rs:** ✅ реализовано — `crates/ss13_game/src/defenses/server.rs`: по типу — ИИ (стреляет во всех вне фракции), синдикат (фракция Syndicate, всегда поднята, баллистика из своих `stun/lethal_projectile`), шаттловая синдиката даёт к первому выстрелу ещё три через 0,5/1/1,5 с (`volley`), руинная энерготурель стреляет во всех, чья надетая ID без её доступа, ЦК-шаттла и вспомогательной базы (по людям не стреляют, нейтральные фракции), лазертаг (цели — команда противника, задержка 3 с); EMP-защита синдиката/ЦК — `crate::emp`. Чужое: ручное управление турелью ИИ (`turret_toggle`, действия и перехват кликов) — ../silicon/ai.md

### Пульт управления турелями
Настенный пульт зоны: включает/выключает все турели зоны и переключает оглушение/убийство; блокируется ID, ИИ может быть отключён от него; Alt-клик — смена режима.

- **Код:** [`/obj/machinery/turretid`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/porta_turret/turret_control.dm#L1), [`/obj/item/wallframe/turret_control`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/porta_turret/turret_control.dm#L233); tgui: [`TurretControl.tsx`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/tgui/packages/tgui/interfaces/TurretControl.tsx)
- **Статус в ss13-rs:** ✅ реализовано — `crates/ss13_game/src/defenses/server.rs` (`TurretControl`, правки карты `enabled`/`lethal`/`locked`/`ailock`/`control_area` в `DmWallMount`), окно `TurretControl` (`crates/ss13_game/src/defenses/client.rs`): все турели `control_area` (или своей зоны) — вкл/выкл, оглушение/убийство, стрельба по киборгам (`setState`, не для емагнутых турелей); ID с `ai_upload` запирает, силикон переключает замок из окна, `ailock` закрывает ИИ; заперто — менять могут только силиконы (на сервере); емаг отпирает навсегда, ЭМИ перемешивает; Alt-клик ИИ — оглушение/убийство, Ctrl-клик — вкл/выкл (кроме `ailock`, `crates/ss13_game/src/silicon/ai.rs`); мультитул с запомненной турелью привязывает её к пульту. Отличие от tg: турель пульта выбирает цели только в зоне пульта (`ControlZone`): в tg лучи проходят стекло, и турели ядра ИИ оглушали прохожих за окнами. Чужое: Alt/Ctrl-клик киборгов (кликов киборгов с модификаторами в порте нет — ../silicon/), рама пульта (сборка настенных машин — ../engineering/)

Пошаговая сборка рамы: металл, гаечный ключ, энергооружие внутрь (определяет снаряды), датчик движения, сварка; крышка турели с замком.

- **Код:** [`/obj/machinery/porta_turret_construct`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/porta_turret/portable_turret_construct.dm#L11), [`/obj/machinery/porta_turret_cover`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/porta_turret/portable_turret_cover.dm#L6)
- **Статус в ss13-rs:** ✅ реализовано — `crates/ss13_game/src/defenses/turret_build.rs` (`TurretFrame`), `ss13_mapload::guns::install_gun`: все шаги рамы (ключ, железо, энергооружие, датчик движения, отвёртка, железо, сварка), откат инструментами и пустой рукой; готовая турель стреляет снарядами установленного оружия, лазертаг даёт турель своей команды, замок ID — в `defenses/server.rs`; ручка переименовывает раму (`Rename`/`Reset`, ответы перепроверяют досягаемость), готовая турель получает это имя (`finish_name`); гаечный ключ и лом готовой турели — пункт «Портативная турель». Общий механизм переименования ручкой (`tool_renaming` у всех `UNIQUE_RENAME`) — ../items/

### Сканер-ворота (scanner gate)
Рамка, сканирующая проходящих в выбранном режиме: майндщит, болезни (порог тяжести), оружие, розыск, вид, голод/полнота; при срабатывании — тревога и красная полоса, можно инвертировать; настройка по ID, панель с проводами, емаг ломает. Пресет на оружие.

- **Код:** [`/obj/machinery/scanner_gate`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/scanner_gate.dm#L9), [`proc/perform_scan()`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/scanner_gate.dm#L192), [`/datum/wires/scanner_gate`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/datums/wires/scanner_gate.dm#L1), [`/obj/machinery/scanner_gate/preset_guns`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/scanner_gate.dm#L372); tgui: [`ScannerGate.jsx`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/tgui/packages/tgui/interfaces/ScannerGate.jsx)
- **BandaStation:** [`modular_bandastation/tts/code/base_seeds/objs/objs.dm`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/modular_bandastation/tts/code/base_seeds/objs/objs.dm#L189) — голос TTS у сканер-ворот
- **Статус в ss13-rs:** ✅ `crates/ss13_game/src/defenses/scanner_gate.rs` (`ScannerGate`, `perform_scan`), окно `ScannerGate` (`defenses/client.rs`), провода (`machine_wires.rs`): все режимы (майндщит, болезнь с порогом, оружие с допуском/майндщитом, розыск, вид включая подтипы и спящих зомби, голод/ожирение), инверсия, ложные срабатывания, тревога и полосы сканирования, замок ID, панель и провода (импульс на сборку при срабатывании/промахе), емаг снимает замок, пресет на оружие. Нет поворота ключом, тира сканирующих модулей (фиксировано как у базовых деталей), расхода энергии на скан, `TRAIT_CONTRABAND_BLOCKER`, ворот люкс-шаттла (группа шаттла), TTS-голоса (группа TTS); розыск ищет запись по настоящему имени, как турель

### Баррикады
Блокирующие проход структуры: деревянные (из досок, грубые, снежные), мешки с песком, охранная баррикада; ломаются уроном, частично защищают от выстрелов.

- **Код:** [`/obj/structure/barricade`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/deployable.dm#L11), [`/obj/structure/barricade/wooden`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/deployable.dm#L66), [`/obj/structure/barricade/sandbags`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/deployable.dm#L113), [`/obj/structure/barricade/security`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/deployable.dm#L132)
- **Статус в ss13-rs:** ✅ реализовано — `crates/ss13_game/src/defenses/barricades.rs`: плотные ломающиеся баррикады всех подтипов (`obj_damage`), `proj_pass_rate` по типу и проход выстрелов от соседнего стрелка (`projectile.rs`), сварка металлических (4 с, 10 топлива), лом деревянных, обломки досок, доски на двери и окна (грубая баррикада за 5 с); на мешки с песком забираются перетаскиванием себя, как на стол (`climbable`, `crates/ss13_game/src/tables.rs`); охранная баррикада держит выстрелы бронёй 50 (bullet/laser/energy, `projectile_armor`, `obj_damage::take_damage_armor`). Нет: подъёма стоящего на мешках на 12 px (`elevation`), прохода с уже занятого баррикадой тайла (бывает только при развёртывании гранаты на человеке)

### Граната-баррикада и складной пулемёт
Граната охраны разворачивает баррикаду выбранного типа (стена, коридор, ...); складной тяжёлый пулемёт разворачивается в стационарную турель.

- **Код:** [`/obj/item/grenade/barrier`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/deployable.dm#L149), [`/obj/item/deployable_turret_folded`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/machinery/deployable.dm#L205)
- **Статус в ss13-rs:** ✅ граната — `crates/ss13_game/src/grenades.rs` (`Kind::Barrier`), `defenses/barricades.rs` (`deploy`, `toggle_barrier`): одиночный/вертикальный/горизонтальный режим по Alt-клику (и в слоте), центр ставится всегда, бока — на свободные тайлы; складной пулемёт — уже был в `crates/ss13_game/src/deployable_turrets.rs`. Нет кнопки действия гранаты (`ui_action_click`)
