# Служба безопасности

Всё, что обслуживает охрану станции: средства задержания (наручники, путы, дубинки, вспышки), уровни угрозы и ключ-карты глав, камеры наблюдения и консоли, записи экипажа и преступлений с охранным HUD, бриг с таймерами и трудовой лагерь, турели и сканер-ворота, криминалистика детектива, импланты, а также форковый взлом шкафов. Толчок/обезоруживание — в разделе боя, оружие (тазеры, дизейблеры) — в разделе оружия, очки HUD как одежда — в ../items/. В ss13-rs реализованы дубинки, ручные вспышки и наручники (`crates/ss13_game/src/security.rs`, `restraints.rs`); остальная часть раздела пока отсутствует.
