# Модпаки BandaStation

Каталог всех модпаков `modular_bandastation/*` форка BandaStation: что делает каждый и в каком разделе каталога он разобран подробно. Модпаки, которые не относятся ни к одному другому разделу (сапёр, правки баланса, отключения апстрима, общие компоненты, служебная инфраструктура, чейнджлог, автовики), описаны записями в этой папке.

| Файл | Что внутри |
| --- | --- |
| [modpacks.md](modpacks.md) | Таблица всех 98 модпаков со ссылками на `_<name>.dm` и разделы каталога (без статусов) |
| [balance.md](balance.md) | Модпак `balance`: скорость, оружие, торгоматы, медицина, мобы, события, трейты |
| [fork-misc.md](fork-misc.md) | Сапёр, overrides, компоненты форка, отчёт о вышедших, чейнджлог, автовики, служебная инфраструктура |
