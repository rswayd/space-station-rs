# Языки
Система языков: кто какие языки понимает и на каких говорит, искажение непонятной речи, меню языков, учебники.

### Датум языка и искажение речи
`/datum/language`: ключ, иконка, «слоги» для скрамбла непонятной речи, флаги (только письменный, табу для призраков); непонимающий слышит набор слогов.

- **Код:** [`/datum/language`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/language/_language.dm#L7), [`/atom/movable/proc/translate_language()`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/game/say.dm#L311)
- **Статус в ss13-rs:** ✅ реализовано — `crates/ss13_chat/src/language.rs`, `language/defs.rs` (`LanguageId`, `LanguageDef`, `scramble_paragraph`, `translate`): все 28 языков tg и BandaStation с ключами, флагами, слогами (сгенерированы из DM), шансами, приоритетом и взаимопониманием; непонимающий слышит слоги по предложениям и словам (детерминированно от зерна раунда — замена кешей tg), частичное понимание оставляет слова, крик остаётся криком (для любого алфавита — у tg регулярка только латинская); без языка — «издаёт странный звук.»; ярлык языка `(Draconic) ` перед именем вместо иконки; `// shortcut:` нет списка 1000 частых английских слов, кодспик — слогами общего вместо кодовых фраз, нет генерации имён и шрифтов языков

### Хранилище языков
`/datum/language_holder`: понимаемые и разговорные языки моба от вида, органа-языка, квирков, предметов; источники (`LANGUAGE_MIND`, `LANGUAGE_ATOM`...), выбранный язык по умолчанию.

- **Код:** [`/datum/language_holder`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/language/_language_holder.dm#L38), [`/datum/language_holder/alien`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/language/_language_holder.dm#L356)
- **Статус в ss13-rs:** ✅ реализовано — `crates/ss13_chat/src/language.rs` (`LanguageHolder`, `Preset`, `Tongue`): понимаемые/разговорные/заблокированные по источникам, частичное понимание, omnitongue, выбор по `default_priority`, все пресеты `/datum/language_holder/*`; ограничения языка-органа (`languages_native`, ксено, робо), без языка — только `TONGUELESS_SPEECH`; тело без хранилища — `atom_basic` (общий); призраки и мёртвые понимают всё; ключ `,x` (`crates/ss13_chat/src/speech.rs`, `parse_mods_speaking`); перевод в местной речи, шёпоте и радио (`crates/ss13_game/src/radio.rs`); источники: вид, язык-орган (робо-язык даёт EAL), афазия, поглощение генокрада, культ, спящий карп, квирк

### Меню языков
TGUI-окно: известные языки, выбор языка по умолчанию; админ может выдавать/забирать языки.

- **Код:** [`/datum/language_menu`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/language/_language_menu.dm#L1); tgui: [`LanguageMenu.tsx`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/tgui/packages/tgui/interfaces/LanguageMenu.tsx)
- **Статус в ss13-rs:** ✅ реализовано — `crates/ss13_game/src/language_menu.rs`, клиент `language_menu_client.rs`: кнопка `talk_wheel` на HUD каждого игрока (headless tgui, без изменения протокола) открывает окно: языки, которые моб говорит/понимает/понимает частично, может ли говорить физически, ключ, язык по умолчанию (`select_default` с проверкой `can_speak_language` в момент действия); админ-режим (выдать/забрать язык, omnitongue) — 🟡 в группе админки

### Учебники языков и билингвизм
Книги-учебники (кодспик, языки рас, пиратский, дронский) учат языку; квирк «Билингв» даёт второй язык.

- **Код:** [`/obj/item/language_manual`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/language/_language_manuals.dm#L1), [`/obj/item/language_manual/codespeak_manual`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/language/_language_manuals.dm#L53), [`/datum/quirk/bilingual`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/datums/quirks/positive_quirks/bilingual.dm#L1)
- **BandaStation:** [`bilingual_add.dm`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/modular_bandastation/language_improvements/code/bilingual_add.dm#L1) — Неорусский в выборе билингва
- **Статус в ss13-rs:** ✅ готово — учебники: `crates/ss13_game/src/language_manuals.rs` (`LanguageManual`, клики `AttackSelf` 3396 и `HeldOnTarget` 236): чтение в руке учит языку (говорить и понимать, снимает блокировки, `babel`), удар по голове живого учит его (источник `Mind`), уже знающего или чужака дронский учебник просто бьёт, мёртвого шлёпает; заряды (кодспик 1 / роскошный ∞, пиратский 5, дронский ∞ только дронам и синтетикам, видовые 1/5/∞), последний заряд превращает книгу в случайное руководство (`holodeck::MANUALS`); видовой учебник при появлении берёт язык из `uncommon_roundstart_languages` и имя по нему (баг tg — `language = common` у базы, из-за чего все видовые учат общему, — не перенесён; драконий учит драконьему). Квирк «Bilingual» — `crates/ss13_game/src/quirks/` (`bilingual`): случайный язык рас (или старогалактический). Тесты: `language_manuals.rs` (`kinds_follow_the_type_tree`), `tests/it/language_items.rs` (`manuals_teach_and_wear_out`). Нет: выбора языка билингва и прочих настроек квирка в префах — контракт лобби (`docs/parity/ui/preferences.md`)
