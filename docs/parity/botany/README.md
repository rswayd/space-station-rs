# Ботаника

Гидропоника tg (`code/modules/hydroponics`): лотки и грядки с циклом воды, удобрений, сорняков, вредителей и токсинов; семена со статами и генами (трейты, реагенты, прививки, мутации от химии и радиации); десятки семейств растений, от еды для кухни до опасных и особых (реплика-под, кудзу, гатфрукт); экстрактор семян, биогенератор, анализатор растений, бродильная бочка, инструменты и пчеловодство. Генный модификатор (DNA manipulator) в текущем tg удалён, его роль выполняют прививки. Форк (`modular_bandastation/hydroponics`) добавляет дизайны биогенератора и правит несколько генов. В ss13-rs есть основа гидропоники (`crates/ss13_game/src/botany/`, данные `crates/ss13_mapload/src/plants.rs`): семена и гены из DM, цикл лотка с ~40 реагентами, мутации, опыление, урожай, экстрактор семян и анализатор в чат; нет биогенератора, автополива, прививок, трейтов продукта, пчёл.
