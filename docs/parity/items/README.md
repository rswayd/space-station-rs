# Предметы, одежда и хранилища

Раздел каталога о предметах общего назначения: вся одежда (`code/modules/clothing`) по семействам и её механики (слоты, броня, защита от среды, аксессуары), хранилища (`/datum/storage`: рюкзаки, пояса, коробки), газовые баллоны и джетпаки, фонари и курение, игрушки, мелки и наклейки, гранаты, ID-карты с тримами, устройства из `code/game/objects/items/devices`, шкафы и ящики (`crates_lockers`), а также модпаки форка `modular_bandastation/objects` и `modular_bandastation/aesthetics`. В ss13-rs из этого есть надевание одежды по слотам с защитой от давления, холода, тока и вспышек, хранилища с лимитами, баллоны для дыхания, ID-доступ, шкафы и гранаты (флешбанг, ЭМИ, дымовая, мини-бомба, осколочные, кластерные, C-4/X-4); остальные механики предметов почти не перенесены.
