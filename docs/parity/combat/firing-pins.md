# Бойки (firing pins)
Боёк в оружии решает, кто и где может стрелять; без бойка оружие не стреляет.

### Механика бойка
Боёк проверяется при каждом выстреле (`pin_auth`); при отказе — сообщение и, у некоторых, наказание; боёк можно извлечь и вставить другой (уничтожая старый), исследуется в РнД.

- **Код:** [`/obj/item/firing_pin`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/projectiles/pins.dm#L1), [`proc/pin_auth()`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/projectiles/pins.dm#L76), [`proc/auth_fail()`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/projectiles/pins.dm#L84), [`proc/gun_insert()`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/projectiles/pins.dm#L63)
- **Статус в ss13-rs:** ✅ реализовано — `crates/ss13_game/src/guns.rs`: без бойка спуск заблокирован, стандартный боёк разрешает всем; бойки не снимаются и не меняются

### Бойки по допуску и местоположению
Импланта майндшилда, синдикатский (`pindicate`), тира (только на стрельбище), исследовательский (только вне станции), ДНК-привязанный, платный (paywall), лазертаг-команд, обезьяний, клоунские (самоуничтожение у ultra).
