# Мини-игры
Внераундовые активности для призраков и выбывших.

### Мафия
Игра для призраков на отдельной карте: роли города, мафии-генокрадов и нейтралов (16 ролей), день/ночь, голосования, способности; панель `MafiaPanel`; достижения.

- **Код:** [`/datum/mafia_controller`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/mafia/controller.dm#L12), [`/datum/action/innate/mafia_panel`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/mafia/controller.dm#L856), [`code/modules/mafia/roles`](https://github.com/ss220club/BandaStation/tree/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/mafia/roles); tgui: [`MafiaPanel.tsx`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/tgui/packages/tgui/interfaces/MafiaPanel.tsx)
- **Статус в ss13-rs:** ❌ нет — есть только общее меню мини-игр призрака (`crates/ss13_game/src/minigames/mod.rs`, кнопка добавится вместе с игрой)

### Захват флага (CTF)

- **Код:** [`/datum/ctf_controller`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/capture_the_flag/ctf_controller.dm#L5), [`/datum/ctf_team`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/capture_the_flag/ctf_controller.dm#L191), [`/obj/machinery/ctf/spawner`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/capture_the_flag/ctf_game.dm#L26), [`/obj/item/ctf_flag`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/capture_the_flag/ctf_game.dm#L184); tgui: [`CTFPanel.tsx`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/tgui/packages/tgui/interfaces/CTFPanel.tsx)
- **Статус в ss13-rs:** ❌ нет — есть общее меню мини-игр призрака и каркас лобби/арены (`crates/ss13_game/src/minigames/`, кнопка добавится вместе с игрой)

### Дезматч
Лобби дезматча для призраков: выбор карты, наборов снаряжения и модификаторов, бой до последнего.

- **Код:** [`/datum/deathmatch_controller`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/deathmatch/deathmatch_controller.dm#L1), [`/datum/deathmatch_lobby`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/deathmatch/deathmatch_lobby.dm#L1); tgui: [`DeathmatchPanel.tsx`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/tgui/packages/tgui/interfaces/DeathmatchPanel.tsx)
- **Статус в ss13-rs:** 🟡 частично — `crates/ss13_game/src/minigames/deathmatch.rs`, `minigames/mod.rs`, `minigames_ui.rs`, `minigames_client.rs`: кнопка «Дезматч» в меню мини-игр; окно `DeathmatchPanel` (список лобби по ключу хоста, «Создать лобби» после начала раунда с оповещением призраков, «Войти» — игроком или наблюдателем, если карта заполнена, «Смотреть» — наблюдателем, во время боя призрак переносится на арену); окно `DeathmatchLobby` (игроки с готовностью и снаряжением, «Случайно»; наблюдатели; хост меняет карту — лишние игроки уходят в наблюдатели, недопустимые наборы сбрасываются, — выгоняет, передаёт хоста, переводит в наблюдатели и обратно, стартует при ≥2 игроках; старт сам, когда все готовы; уход хоста передаёт лобби; лобби без старта 5 минут закрывается; отключившиеся и вселившиеся в тело выбывают из лобби). Бой: карта грузится на новый уровень (`load_template_with`, спавны-ландмарки снимаются), через 8 с каждый призрак-игрок получает человека со своим персонажем на случайном спавне в своём наборе (`temporary_body`), наблюдатели переносятся на арену; погибший/вышедший из тела/удалённый выбывает в наблюдатели (живое брошенное тело — в пепел), объявление «X ПОГИБАЕТ. ОСТАЛОСЬ: N.»; при одном оставшемся или по истечении времени карты — «ПОБЕДИТЕЛЬ», тела удаляются, уровень зачищается, лобби закрывается, призраки могут вернуться в прежние тела. Карты: 6 из 25 (Maint Mania, Meat Tower, OSHA Violator, Ragecage, Sunrise, The Brig) с наборами ассистента, шеф-повара и самурая. Тесты: `crates/ss13_game/tests/it/minigames.rs` (`ghosts_fight_a_deathmatch_until_one_is_left`), юнит-тесты в модуле. Нет: остальных 19 карт и их наборов (заклинания, мутации, смена вида, оружие), модификаторов (`/datum/deathmatch_modifier`), админских функций (принудительный старт, закрытие лобби, `GHOSTROLE_MINIGAME`), ссылки «Join» в чате призраков, содержимого рюкзака/коробки наборов; каждый бой оставляет пустой уровень (как баскетбол)

### Баскетбол
Командный баскетбол призраков с рефери и картами.

- **Код:** [`/datum/basketball_controller`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/basketball/controller.dm#L19); tgui: [`BasketballPanel.tsx`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/tgui/packages/tgui/interfaces/BasketballPanel.tsx)
- **Статус в ss13-rs:** 🟡 частично — `crates/ss13_game/src/minigames/basketball.rs`, `minigames/mod.rs`, `minigames_ui.rs`, `minigames_client.rs`: кнопка «Мини-игры» в HUD призрака и окно `MinigamesMenu` (баскетбол и дезматч); лобби `BasketballPanel` (запись/отписка по ключу, отключившиеся остаются в списке, не-призраки выбывают, старт записавшимся при 2–7 подключённых призраках, лишние — случайно отсеяны с сообщением); стадион — случайная карта из 8 (`_maps/minigame/basketball`, грузится на новый уровень через `ss13_mapload::load_template_with`, ландмарки снимаются в `prepare`), кольца получают имена домашней и случайной гостевой команды; игроки по очереди дом/гости, при нечётном числе последний — судья; тело с персонажем игрока в форме команды (всё `NODROP`), без дыхания/горения (`species::has_trait`), пацифист (`traumas::refresh`), без оглушений (`stunmod = 0`); 3 минуты игры, отсчёт последних 10 секунд кольцами, победа по очкам (ничья), проигравшие — в пыль, через 20 с тела удаляются, уровень зачищается, призраки снова могут вернуться в прежние тела (`temporary_body`). Кольца (`Hoop`): бросок в кольцо — шанс по дальности 95…20%, вдвое меньше без клика по кольцу, 3 очка дальше 2 клеток (`throw.rs` → `hoop_hitby`); данк любым предметом по соседнему кольцу (2 очка, 20 выносливости с мячом); данк моба в агрессивном захвате (паралич 10 с, 30 выносливости); очки считает только мяч, забивший 3 с не может поднять мяч; кольцо мини-игры не засчитывает свою команду. Мяч: попав в карбона, оказывается у него в руках; клик мячом по карбону вне боевого режима — передача. Тесты: `crates/ss13_game/tests/it/minigames.rs`, юнит-тесты в модуле. Нет: свистка судьи «Call foul» (таймстоп — в порте нет `/obj/effect/timestop`), дриблинга/вращения/шанса отбора по выносливости, броска ПКМ поверх голов (`PASSMOB`), потери мяча при сбивании с ног, табло на кольцах, коляски для безногих, случайного роста, имён «Alien (N)» на ID ксеноморфов, админского флага `GHOSTROLE_MINIGAME`; каждый матч оставляет пустой уровень (как домены битраннеров)
