# Семейства реагентов
Группы реагентов с их эффектами на мобов. В ss13-rs все реагенты существуют как данные и метаболизируются; эффекты (`on_mob_life`) есть у стартового набора (`crates/ss13_reagents/src/metabolism.rs`) и у семейств с собственными модулями игры (наркотики, пиротехника), которым метаболизм передаёт `Body::metabolized`.

### Медицина второго поколения (cat2)
Либитал (brute, вредит печени), аиури (burn, вредит глазам), мультивер (токсины, лучше в одиночку), конвермол (oxy, травит), а также гельтеобульбин, синтплоть (лечит хаска), пенацетил, сеирьиум и прочие «c2».

### Наркотики
Космические наркотики, метамфетамин, никотин, бат-соли, крокодил, счастье, грибы и др.: эффекты, передозировки, зависимости.

- **Код:** [`/datum/reagent/drug`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/reagents/chemistry/reagents/drug_reagents.dm#L1), [`/datum/reagent/drug/space_drugs`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/reagents/chemistry/reagents/drug_reagents.dm#L12), [`/datum/reagent/drug/methamphetamine`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/reagents/chemistry/reagents/drug_reagents.dm#L162), [`/datum/reagent/drug/nicotine`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/reagents/chemistry/reagents/drug_reagents.dm#L81)
- **Статус в ss13-rs:** 🟡 частично — `crates/ss13_game/src/drugs.rs`: `on_mob_life`, передозировки и начало/конец метаболизма с `metabolization_ratio` tg для космических наркотиков, каннабиса, никотина, крокодила (сход кожи при чистоте ≤ 60% на 36-м цикле), метамфетамина (ускорение шага), солей для ванн, аранеспа, счастья, памп-апа, мусорных порошка/слизи/смолы, грибного галлюциногена, кронкаина (ускорение действий), синдола; моодлет передозировки у любого реагента; зависимости — `crates/ss13_game/src/addictions.rs`. Нет blast-off, saturn-x, gore и кокаина BandaStation; психоза солей для ванн, цветовых фильтров экрана, звуков кронкаина, `stoned`, метаболизма «мусорной» печени, бреда синдола (случайные галлюцинации); шаги — один запрос движения за тик
