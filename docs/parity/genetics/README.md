# Генетика

Генетика оригинального сервера: датум ДНК (идентичность, особенности, энзимы, последовательности мутаций), нестабильность генома, все группы мутаций, сканер и консоль ДНК, инъекторы, ДНК-инфьюзер, экспериментальный клонер, ДНК-зонд и хранилище. Источники: `code/datums/dna`, `code/datums/mutations`, `code/game/machinery/dna_scanner.dm`, `code/game/machinery/computer/dna_console.dm`, `code/game/machinery/dna_infuser`, `code/game/machinery/experimental_cloner`; форк — блоки особенностей видов и мутационные токсины в `modular_bandastation/species`. В ss13-rs генетики нет совсем: у мобов нет ДНК, мутаций и связанных машин.

| --- | --- |
| [dna.md](dna.md) | датум ДНК и блоки, нестабильность, случайные мутации, мутационные токсины форка |
| [mutations.md](mutations.md) | механика мутаций, халк, активные силы, пассивные бонусы, недостатки, речевые, обезьяна, ауры |
| [genetics-machines.md](genetics-machines.md) | сканер и консоль ДНК, инъекторы, ДНК-инфьюзер, экспериментальный клонер, ДНК-зонд и хранилище |
