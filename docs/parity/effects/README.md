# Эффекты, освещение и окружающая среда (effects)

Механики окружающей среды BandaStation, не принадлежащие одному отделу: взрывы и ЭМИ (`SSexplosions`), погода (`SSweather`), метеоры, движок освещения (`SSlighting`), радиация (`SSradiation`), эффект-системы (искры, дым и пена через `SSfluids`, брызги, следы, частицы), декали и грязь, а также служебные эффекты карты: точки спавна, спавнеры лута, временные визуалы, постеры, мины, порталы, силовые поля. В ss13-rs из этого есть почти полное статическое освещение (клиент `ss13_render`), точки спавна профессий и статические спавнеры лута при загрузке карты; декали и постеры только рисуются из карты; взрывов, погоды, метеоров, радиации, дыма и пены нет. Пожар и горячие точки описаны в ../atmos/, светильники и их питание в ../power/, события, которые вызывают эти эффекты, в ../events/.
