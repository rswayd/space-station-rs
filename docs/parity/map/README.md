# Карты

Станции из `_maps/map_jsons` и всё, что загружает мир: конфиг карты, чтение `.dmm`, z-уровни, мульти-Z, резервации, маппинг-хелперы, случайные спаунеры, голосование за карту, CentCom, Лаваленд и ледяная луна, руины, экспедиции, а также модули форка (автомаппер, спаун по зонам, наномапа). В ss13-rs есть общий загрузчик `.dmm` (`crates/ss13_mapload`), на котором полностью играется только MetaStation; уровни без связи по вертикали, CentCom и планеты не грузятся. Шаттлы — ../shuttles/, лестницы/openspace как объекты — ../engineering/, виртуальные домены — ../science/, Deathmatch — ../round/.
