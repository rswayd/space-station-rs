# Администрирование

Админ-система BandaStation: права и вербы, панели игроков и раунда, баны и заметки, тикеты, события и смайты, билдмод, отладка, логи, интервью, Discord/TGS и модпаки `admin`, `ticket_manager`, `discord`, `world_topics`, `metaserver`, `prime_only`. В ss13-rs — базовая админ-система `crates/ss13_admin` (ранги и права из текстового конфига, вербы, тикеты, asay, админ-лог; `docs/RUNNING.md`, «Admins») и отладочный UI разработчика (`crates/ss13_debug`).
