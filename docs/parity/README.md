# Каталог паритета: BandaStation → ss13-rs

Полный перечень того, что есть в оригинальном сервере [BandaStation](https://github.com/ss220club/BandaStation) (форк tgstation для сообщества SS220) на коммите [`ce5b1f1`](https://github.com/ss220club/BandaStation/tree/ce5b1f159748db35281bd3b673551598807f4a0b), и насколько это реализовано в ss13-rs. Каталог нужен, чтобы отслеживать прогресс переписывания: каждая механика, семейство объектов, подсистема или окно — отдельная запись с её статусом.

## Как читать

- Одна папка — одна область (атмос, энергетика, мобы, антагонисты, ...). Области выведены из раскладки исходников: `code/modules/*`, `code/datums/*`, `code/game/*`, `code/controllers/subsystem/*`, `modular_bandastation/*`. В каждой папке `README.md` с обзором и таблицей файлов; каждый файл — одна система или группа функций и читается отдельно.
- Запись имеет вид:
  - **Название** (заголовок `###`) и 1–3 предложения о том, что это делает в игре;
  - **Код:** постоянные ссылки на GitHub на коммит выше, на строку определения главного типа или процедуры; tgui-интерфейс, если он есть;
  - **BandaStation:** только если форк меняет механику — ссылка на `modular_bandastation/...` или на маркер `BANDASTATION EDIT/ADDITION/REMOVAL` в апстримном файле;
  - **Статус в ss13-rs:** с путём к модулю Rust, если что-то есть.
- Статус проверен по коду ss13-rs (`crates/*`), а не по названиям; пробелы, которые сами модули отмечают комментариями `// shortcut:`, перечислены в 🟡-записях. Состояние ss13-rs — `main` на коммите `735c8af` (PROTOCOL_VERSION 59): записи обновлялись при слиянии каждой ветки; 2026-11-02 сверены записи ❌, чьи типы tg встречаются в коде (`crates/*`), и обзоры областей. Индекс пересчитывается `python3 scripts/parity-count.py`.
- Семейства (все очки, все гранаты, все виды мобов) сгруппированы в одну запись, заметные исключения названы в тексте.
- Каждая функция описана в одной папке; в других папках на неё есть только перекрёстная ссылка («см. ../<папка>/» или строка «_«Название» описано в ../<папка>/<файл>.md_») без статуса. Модули форка описаны в папке своей области; [bandastation/](bandastation/) — сводная таблица всех модпаков `modular_bandastation/*` со ссылками на эти папки плюс модули, которые больше никуда не относятся.

## Легенда статусов

| Значок | Значение |
| --- | --- |
| ✅ реализовано | поведение есть в ss13-rs и совпадает с оригиналом в том, что видит игрок |
| 🟡 частично | есть основа или часть; в записи сказано, чего не хватает |
| ❌ нет | в ss13-rs этого нет |

Подсчёт: `grep -rh "\*\*Статус в ss13-rs:\*\*" docs/parity | cut -c1-40 | sort | uniq -c` — у каждой записи ровно одна такая строка.

## Как обновлять

Когда ветка ss13-rs вливается в master, в той же или следующей ветке обновляются записи областей, которые она затронула:

1. По диффу ветки (`git diff <база>..<ветка> --stat -- crates docs/RUNNING.md`) понять, какие системы появились или изменились, и прочитать их модули вместе с комментариями `// shortcut:`.
2. Найти записи этих систем во всех папках, а не только в «своей»: `grep -rn "<тип DM или ключевое слово>" docs/parity` (КПК, например, упоминается в comms/, round/, ui/, antagonists/).
3. Поменять строку `**Статус в ss13-rs:**` (✅/🟡/❌ с путём к модулю Rust и тем, чего не хватает) по коду, а не по названию ветки; описание и ссылки на оригинал не трогать.
4. Пересчитать таблицу индекса ниже (`grep -rh "\*\*Статус в ss13-rs:\*\*" docs/parity | cut -c1-40 | sort | uniq -c` по папкам) и строку «Состояние ss13-rs» выше.
5. Новая механика, которой в каталоге нет, добавляется записью в папку своей области по общему формату.

## Что покрыто тонко

- Большие семейства сведены в групповые записи: ~700 реагентов, ~1100 блюд, ~190 эмоций, ~380 админ-вербов (по категориям), 72 трейта станции, гост-роли, пути еретика, приложения NtOS, модули законов, улучшения киборгов, снаряжение мехов, узлы техвеба, домены битраннинга, декоративные структуры, трубы по слоям и цветам.
- Не описаны отдельно: шпионские устройства из `items/devices` (`traitordevices`, `chameleonproj`, `powersink`), `aicard`, `pipe_painter`, аркадные автоматы, общий механизм меню крафта, конвейеры, параллакс как отдельная механика; `code/modules/unit_tests` и `autowiki` пропущены намеренно (тестовая и вики-инфраструктура).
- Статусы ✅ у части записей (рецепты коктейлей, перерисовки спрайтов форка, профессии форка) выставлены по тому, что конвертер ss13-rs (`ss13_dm_extract` разбирает весь `.dme`, модпаки форка включены) переносит данные, без игровой проверки каждой единицы.
