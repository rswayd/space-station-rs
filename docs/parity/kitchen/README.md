# Кухня и бар

Еда и напитки оригинального сервера: общая механика еды (поедание, вкус, нарезка, порча, баффы), семейства блюд из `code/modules/food_and_drinks/food`, кухонные машины (микроволновка, духовка, сковорода, гриль, фритюрница, плита, комбайн, блендер, гиббер, мороженое, кофеварка), рецепты (меню крафта, кастомная еда, реакции еды, супы, коктейли), хранение и посуда (умные холодильники, сушилки, тарелки, приборы, коробки пиццы, приправы), напитки и бар (посуда, бутылки, газировка, раздатчики, кальян и вывески BandaStation) и система ресторана с роботами-посетителями. В ss13-rs сейчас есть поедание еды с вкусом и мусором, нарезка/раскатка, микроволновка, духовка, сковорода, фритюрница, кухонный комбайн, блендер (только помол), раздатчики газировки и алкоголя, умные холодильники, стили стаканов по напитку, банки газировки и смешивание коктейлей как реакций; голод — вне этой папки.
