# Транспорт и мехи

Транспорт оригинального сервера (`code/modules/vehicles`): базовая система `/obj/vehicle` (ключи, водитель и пассажиры, действия), ездовой транспорт (велосипед, скутеры и скейты, инвалидные кресла, вездеход, сегвей, уборочная тележка, лавовая лодка), закрытые машины (клоунмобиль, гольф-кар) и экзокостюмы-мехи с оборудованием, сборкой, мехфабом, зарядной станцией и консолью слежения. Форк меняет скорость транспорта (`modular_bandastation/balance`), сборку ядер боевых мехов и снаряжение мехов ЦК/ОБР. В ss13-rs есть мехи (`crates/ss13_game/src/mecha/`: Рипли и Одиссей, клешня, бур, сборка, мехфаб — см. [mechs.md](mechs.md)); остального транспорта и верховой езды (buckle) нет.
