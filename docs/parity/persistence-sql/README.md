# База данных и персистентность

Хранение данных между раундами и вне игры: SQL-база (`SSdbcore`, схема tg и таблицы BandaStation `database220`: игроки, подключения, раунды, баны, заметки, наигранное время, опросы, библиотека, достижения, blackbox, IP-интел, стикибаны) и файловая персистентность `SSpersistence` (трофеи, картины, гравировки, фото, шрамы, бутылки, счётчики). В ss13-rs нет ни БД, ни персистентности: каждый раунд начинается с чистого мира.

| [persistence.md](persistence.md) | SSpersistence: трофеи, картины, гравировки, фото, шрамы, бутылки, копилки, счётчики, аутфиты |
