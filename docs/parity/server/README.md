# Серверная инфраструктура

То, что игроки замечают в работе сервера: Master Controller и служебные подсистемы (таймеры, GC, AFK, лаг-свитчи, ввод, пинг), визуальные подсистемы и доставка ассетов, звук, TTS BandaStation, запуск/перезагрузка мира, world topic, подключение клиентов и конфигурация. Включает модпаки `tts`, `sounds`, `aesthetics_sounds` и систему модпаков. ss13-rs — Bevy-сервер с собственной сетью (`crates/ss13_net`, WebTransport), офлайн-конвертацией ассетов (`crates/ss13_mapload`) и клиентским рендером (`crates/ss13_render`); звука нет.
