# Приложения NtOS
Программы модульных компьютеров `/datum/computer_file/program`, сгруппированные по назначению.

### Загрузчик программ (NTNet Software Download)
Каталог программ NTNet с фильтром по доступу и типу устройства, скачивание с учётом места и сигнала; запрещённые программы при емаге.

- **Код:** [`/datum/computer_file/program/ntnetdownload`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/modular_computers/file_system/programs/ntdownloader.dm#L1); tgui: [`NtosNetDownloader.tsx`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/tgui/packages/tgui/interfaces/NtosNetDownloader.tsx)
- **Статус в ss13-rs:** ✅ есть — `crates/ss13_game/src/modpc/programs/downloader.rs`: NT Software Hub на каждом КПК и консоли (`default_programs`), каталог программ порта с флагом `PROGRAM_ON_NTNET_STORE` по категориям, совместимость с устройством (КПК/консоль), доступ по ID в слоте (`download_access`, сервер проверяет доступ и железо — в tg только UI), ёмкость диска (КПК 64, главы и консоли 128 GQ), скачивание 0.5 GQ/с, пока хаб открыт или свёрнут, обрыв при закрытии/выключении, ошибка I/O, значки `downloader_running/finished` в шапке; `// shortcut:` NTNet всегда с хорошим сигналом, нет сетевых логов и каталога Синдиката (нет антагонистских программ в порте)

### Мессенджер КПК
Личные сообщения между КПК через сервер сообщений: список контактов, фото, рингтоны, отправка всем (у глав), спам, режим «невидимки»; корректная работа требует телекомов.

- **Код:** [`/datum/computer_file/program/messenger`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/modular_computers/file_system/programs/messenger/messenger_program.dm#L8), [`messenger_data.dm`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/modular_computers/file_system/programs/messenger/messenger_data.dm#L54); tgui: [`NtosMessenger`](https://github.com/ss220club/BandaStation/tree/ce5b1f159748db35281bd3b673551598807f4a0b/tgui/packages/tgui/interfaces/NtosMessenger)
- **Статус в ss13-rs:** 🟡 частично — `crates/ss13_game/src/modpc/programs/messenger.rs`: контакты всех привязанных КПК станции, чаты с историей и непрочитанными, кулдаун 1 с, рингтон и «Ringer: Off», `*beep*` рядом с получателем; `// shortcut:` без телекомов (сообщение доходит сразу), нет фото, рассылки всем, вирусов, ретрансляции призракам, глушилок

### Чат NTNet Relay Chat
Групповые чат-комнаты с паролями и администратором канала.

- **Код:** [`/datum/computer_file/program/chatclient`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/code/modules/modular_computers/file_system/programs/chatroom/ntnrc_client.dm#L11); tgui: [`NtosNetChat.jsx`](https://github.com/ss220club/BandaStation/blob/ce5b1f159748db35281bd3b673551598807f4a0b/tgui/packages/tgui/interfaces/NtosNetChat.jsx)
- **Статус в ss13-rs:** ✅ есть — `crates/ss13_game/src/modpc/programs/chat.rs`: Chat Client на консоли идентификации и в NT Software Hub; каналы станции (до 50 сообщений, `MAX_CHANNELS`), создатель — оператор (переименование, удаление, пароль, мут), вход в запароленный канал паролем в чате, передача оператора при уходе, пинг с кулдауном 3 с и уведомление `alert_call` на компьютере, ник `DefaultUser###` и смена ника, онлайн/отошёл/оффлайн по состоянию программы, значки `ntnrc_idle/new` в шапке, режим админа по `ACCESS_NETWORK`, очистка участников при удалении компьютера; `// shortcut:` нет сохранения логов (нет текстовых файлов), лога чата для админов и консолей отдельных отделов (`cargochat`); не портирован баг tg — не-участник не может писать в запароленный канал после неверного пароля
