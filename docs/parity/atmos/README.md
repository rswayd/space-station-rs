# Атмосфера

Атмосферика BandaStation (tg): тайловая симуляция воздуха LINDA в подсистеме `SSair`, 20 газов и их реакции, атмосферные пожары, трубные сети с насосами, фильтрами, вентиляциями и скрубберами, портативные канистры, воздушные тревоги, продвинутые машины (электролизёр, кристаллизатор, Hypertorus) и газоанализатор. Источники: `code/modules/atmospherics`, `code/datums/atmosphere`, `code/controllers/subsystem/air.dm`, а также `code/game/machinery/computer/atmos_*`, `code/game/machinery/pipe`, газоанализатор и баллоны из `code/game/objects/items`. В ss13-rs (`crates/ss13_atmos`, `crates/ss13_game/src/{atmos,fire,internals}.rs`) реализованы тайловая часть (LINDA, реакции, хотспоты, ветер давления), трубные сети (`crates/ss13_atmos/src/pipenet`) с насосами, фильтрами, смесителями, вентиляциями, скрубберами, термомашиной, портативные канистры, насосы и скрубберы, воздушная тревога (`crates/ss13_game/src/atmos_machinery`), баллоны с internals и газоанализатор. Дыхание — см. ../mobs/.
