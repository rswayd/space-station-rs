# Наука

Научный отдел и смежные системы оригинального сервера: техвеб и R&D (очки, узлы, латы, детали, экспериментор, гизмо), ордонанс и научные статьи, экспериментальная наука (experisci), ксенобиология и цитология, аномалии и их ядра, эксплоратор-дроны, битраннинг (виртуальные домены), схемы wiremod, MODsuits и их модули, сборки (сигналеры, таймеры, сенсоры), телепорты, гейтвей и спутники. В ss13-rs почти ничего из этого нет: из всего раздела частично есть только профессия битраннера (её можно выбрать, она выдаёт экипировку).
