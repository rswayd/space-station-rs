# Генокрад
Инопланетный паразит-оборотень: поглощает ДНК жертв, меняет облик и покупает способности за генетические очки, тратит химикаты на их применение.

- **Статус в ss13-rs:** 🟡 частично — `crates/ss13_game/src/antag/changeling/server.rs` (`Changeling`, `add_changeling`, `forge_objectives`, `changeling_life`, `roundend_report`), `crates/ss13_game/src/antag/changeling/client.rs`; рулсет `CHANGELING_RULESET` в `crates/ss13_game/src/antag/dynamic.rs` (вес 3, `min_pop` 15, кап `population / 29`): имя улья (`Mr. Alpha`, улей `<имя>-hive`), химикаты 20/75 (+1/с за `Life()`, ¼ в огне, до половины мёртвым), генетические очки 10, цели (поглощения, кража 60%, убийство 70% / изоляция + побег с личностью, побег / побег с личностью), приветствие, окно `AntagInfoChangeling`, антаг-HUD, счётчик химикатов слева (максимум при наведении), админское «make antag» (`AntagRole::Changeling`), улей `:g`/`:п` для генокрадов, мёртвых и призраков (`ss13_chat::speech::ChangelingHivemind`, `hivemind_chat`), отчёт конца раунда с числом генов; нет целей на ИИ, замены целей при крио (BandaStation), мудлета, звука, украденных воспоминаний (только цели поглощённых антагов)
